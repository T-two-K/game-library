## Prepearing and downloading
You can download repository using two options:
### First option (clone repository)
For this way you must open "Git Bash", "Powershell", "CMD" or just "Bash" in your PC. And then write the folowwing commands:
```bash
  git clone https://github.com/T-two-K/game-library.git
  cd game-library
  dotnet restore
  dotnet build
  dotnet run
```
### Second option
If you don't want to bother with commands, then this option is for you.
- Сlick to the green button, with an incription "_Code_";
- Press by button "_Download ZIP_";
- Unzip the archive.

After that you can open Visual Studio and run this project (ctrl + F5), but if you don't have this IDE (Integrate Development Environment) you'd better come to the previous option and complete last five commands (but instead of _cd game-library_ command you need to write full path to your unzip folder).
